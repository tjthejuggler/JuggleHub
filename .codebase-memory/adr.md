2026-05-30: Automatic reliable LED tracking preset decision. To avoid requiring the user to manually set many UI controls for the known-good ball tracking configuration, the hub now centralizes a reliable LED/depth+skeleton preset in SettingsManager.RELIABLE_LED_TRACKING_PRESET. The UI applies this preset automatically after loading settings, persists it to both New3D settings files, sends it to the engine, and exposes a one-click Camera Settings button to re-apply it. This keeps New3D simple mode, depth+LED color blobs, YOLO ball detection off, YOLO pose/skeleton on, held hand-off thresholds, and debug overlays aligned even if stale settings files exist.
